CHEEZIN DEPENDENCY TRACKER & API SETUP INSTRUCTIONS
==============================================================================

[NEON.TECH POSTGRESQL DATABASE SETUP]
------------------------------------------------------------------------------
Step 1: Create a Free Neon.tech Account & Project
  1. Navigate to https://neon.tech and sign up or log in.
  2. Click "Create Project".
  3. Enter project details:
     - Project Name: Blueprint-Engine-DB
     - Database Name: neondb
     - Region: Select nearest AWS region
  4. Click "Create Project".

Step 2: Obtain PostgreSQL Connection String
  1. In the Neon Console Dashboard, locate the "Connection Details" widget.
  2. Ensure "Pooled connection" or "Direct connection" is selected.
  3. Copy the standard Postgres connection string. It will look like:
     postgres://alex:AbC123dEf@ep-cool-darkness-123456.us-east-2.aws.neon.tech/neondb?sslmode=require

Step 3: Format URI for SQLAlchemy Async (asyncpg driver)
  1. Replace the prefix "postgres://" or "postgresql://" with "postgresql+asyncpg://".
  2. Ensure "?sslmode=require" is present for Neon cloud SSL requirements.
  3. Formatted connection string example:
     postgresql+asyncpg://alex:AbC123dEf@ep-cool-darkness-123456.us-east-2.aws.neon.tech/neondb?sslmode=require

Step 4: Update Backend Environment File
  1. Open backend/.env (create from backend/.env.example if missing).
  2. Update the DATABASE_URL variable:
     DATABASE_URL=postgresql+asyncpg://alex:AbC123dEf@ep-cool-darkness-123456.us-east-2.aws.neon.tech/neondb?sslmode=require

------------------------------------------------------------------------------
[JWT AUTHENTICATION ENVIRONMENT KEYS]
------------------------------------------------------------------------------
Add the following keys to backend/.env for JWT security:
  JWT_SECRET_KEY=your_generated_secure_32_character_secret_key_here
  JWT_ALGORITHM=HS256
  ACCESS_TOKEN_EXPIRE_MINUTES=60
